refactor
Behavior-preserving refactoring that makes code simple, human, readable, debuggable and maintainable — Clean Code and SOLID (Uncle Bob) applied to every function, public/main/interface functions turned into story-like orchestration functions built from small well-named calls, pure "engine" logic separated from "accessor" I/O (DB, storage, network, screen rendering), and repeated code unified into small helpers. Use whenever the user asks to refactor, clean up, simplify, humanize, untangle, "make readable/maintainable", split a long function, remove duplication, or review code for clean-code/SOLID — in any language — even if they don't name this skill.

stage-gate
Mandatory end-of-stage checkpoint for any multi-stage development mission. Runs a behavior-preserving refactor pass (the `refactor` skill) on the stage's code, then an independent adversarial review AND a usability/main-use-case pass, scores 0-100, fixes and re-tests in a loop until the score clears 90 with no blocker/critical, logs every iteration, then runs a live demo and stops for the human's explicit approval before the next stage starts. Use automatically at the end of every development stage/milestone — do not wait to be asked.
Agent Skill · Public · main
